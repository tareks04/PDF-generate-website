Scanner Settings

শুধু নিজের বা বিশ্বাসযোগ্য allowlist-based relay ব্যবহার করুন। Relay endpoint-এ ?url= query support থাকতে হবে। CORS এড়াতে public image host-কে server side-এ fetch করতে হয়।

ব্যবহার নির্দেশিকা

  1. প্রথম image page-এর URL Scanner-এ paste করুন।
  2. URL-এ page number থাকলে সেটি শনাক্ত হবে। সঠিক candidate নির্বাচন করুন।
  3. সর্বোচ্চ page নির্ধারণ করে Scan শুরু করুন। 404 / 410 পাওয়া গেলে scan থামবে।
  4. Valid link পছন্দের chapter-এ Merge অথবা Replace দিয়ে Save করুন।
  5. Library থেকে chapter খুলে PDF তৈরি, preview, print অথবা download করুন।
  6. Backup tab থেকে JSON export করে আপনার data সংরক্ষণ করুন।

CORS: browser অন্য domain-এর response পড়তে না পারলে relay ছাড়া scan সম্ভব নয়। 403, 429, timeout বা network error হলে scan pause/stop হতে পারে।
